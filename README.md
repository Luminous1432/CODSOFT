# CODSOFT – Machine Learning Internship

This repository contains the tasks completed as part of the **Machine Learning Internship at CodSoft**.

The internship focuses on applying machine learning and NLP techniques to solve real-world problems using Python.

---

## Internship Details
- Role: Machine Learning Intern  
- Organization: CodSoft  
- Duration: 1 Month  
- Requirement: Completion of at least 3 tasks  

---

## Tasks Overview

### 🔹 Task 1 – Movie Genre Classification
**Goal:** Predict the genre of a movie based on its plot description.  
**Dataset:** IMDb Genre Classification Dataset (Kaggle).  
**Techniques Used:**  
- Text preprocessing  
- TF-IDF Vectorization  
- Logistic Regression  

**Results:**  
- ~48% validation accuracy  
- ~48.7% test accuracy across 25+ genres  

---

### 🔹 Task 2 – Credit Card Fraud Detection
**Goal:** Detect fraudulent credit card transactions using machine learning.  
**Type:** Binary Classification.  

**Models Used:**  
- Logistic Regression (baseline)  
- Random Forest (improved)  

**Best Result:**  
- ~33% recall for fraud class (Class 1)

---

### 🔹 Task 3 – Spam SMS Detection
**Goal:** Classify SMS messages as Spam or Ham using NLP techniques.  
**Dataset:** SMS Spam Collection Dataset (Kaggle).  

**Techniques Used:**  
- Text preprocessing  
- TF-IDF Vectorization  
- Multinomial Naive Bayes  

**Result:**  
- Accuracy: **96.68%**
