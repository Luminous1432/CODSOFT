# CODSOFT – Machine Learning Internship

This repository contains the tasks completed as part of the **CodSoft Machine Learning Internship (Machine Learning)**.

## Tasks Overview

1. **Task 1 – Movie Genre Classification**
   - **Goal:** Predict the genre of a movie based on its plot / description.
   - **Dataset:** IMDb Genre Classification dataset from Kaggle.
   - **Techniques:** Text preprocessing, TF–IDF vectorization, Logistic Regression.
   - **Result:** ~48% validation accuracy and ~48.7% test accuracy across 25+ genres.

2. **Task 2 – Credit Card Fraud Detection**
   - Binary classification using machine learning
   - Baseline: Logistic Regression
   - Improved: Random Forest
   - Best Result: ~33% recall for fraud (class 1)
